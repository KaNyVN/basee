# Basee - Flutter starter

A minimal Flutter project ready for Firebase Authentication lessons. Firebase is **not yet installed or configured**.

## Run in GitHub Codespaces

1. Open this repository in **Code > Codespaces > Create codespace**.
2. Wait for the dev container's `postCreateCommand` to finish installing Flutter and generating the standard platform scaffolding.
3. From the repository root, run:

```bash
export PATH="$HOME/flutter/bin:$PATH"
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
```

4. Open forwarded port **8080** in the Codespaces Ports tab.

If the platform files do not exist yet, run `bash tool/setup.sh` once. You can also run locally with a Flutter installation:

```bash
flutter create --platforms=web,android --project-name basee .
flutter pub get
flutter run -d chrome
```

## Add Firebase later

When ready: `flutter pub add firebase_core firebase_auth`. Then configure Firebase with FlutterFire CLI (`flutterfire configure`) and initialize Firebase in `lib/main.dart`. This repository intentionally contains no Firebase credentials/configuration.

> Standard Android/web platform files are generated by `flutter create .` at setup time and ignored by Git. They will appear in your working directory after setup.
